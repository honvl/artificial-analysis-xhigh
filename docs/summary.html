The highest-scoring models on the Artificial Analysis Intelligence Index at each effort level. Each chart shows a model at the best setting it has at or below that level: a model with no variant at the level appears at its highest setting below it, so a model that only has High is on the max, xhigh and high charts. The thin line under each chart's subtitle prices one full run of the index for the leading Claude and GPT model at that level, at API prices and on a subscription. It divides Artificial Analysis's cost by how much more usage the plan gives than API list prices (Claude Max 20x, $200 a month: 45.3x; ChatGPT: 10.25x), as measured by Paweł Huryn. These are one person's estimates on one model per vendor, so treat the subscription figures as rough.
