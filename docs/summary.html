Top models by effort level

The highest-scoring models on the Artificial Analysis Intelligence Index at each effort level. Each chart shows a model at the best setting it has at or below that level: a model with no variant at the level appears at its highest setting below it, so a model that only has High is on the max, xhigh and high charts. A model with no labelled effort setting could be anything up to max, so it appears only on the max chart, marked with a dagger. Columns use the color Artificial Analysis gives each lab. Data last changed 2026-10-29 18:31 UTC.

The thin bar beside a column is what one full run of the index costs on that lab's subscription, read off the dollar axis on the right. That axis is shared by all four charts, so the bars show how cost falls as effort drops, and it is a different measure from the score, so it has its own scale. It is Artificial Analysis's cost for the run divided by how much more usage the plan gives than API list prices (Anthropic: Claude Max 20x 45.3x, OpenAI: ChatGPT 10.25x, SpaceXAI: SuperGrok + X Premium+ 80x), as measured by Paweł Huryn. Only labs with a measured multiplier get a bar. These are one person's estimates on one model per vendor, so treat the bars as rough. The table views give the exact figures.
