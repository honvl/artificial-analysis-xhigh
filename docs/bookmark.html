Bookmark the xhigh chart

The bookmark URL redirects to the latest chart. If you press your browser's "bookmark this page" shortcut on it, you save the long chart URL it lands on, and that goes stale when the default models change. Use the drag link or paste the URL instead.

Artificial Analysis (xhigh)

Drag the box above onto your bookmarks bar. If the bar is hidden: Chrome and Edge Cmd/Ctrl+Shift+B, Safari View > Show Favorites Bar, Firefox View > Toolbars > Bookmarks Toolbar.

Or paste the URL

  • Chrome: Cmd/Ctrl+Shift+O, the menu at the top right, Add new bookmark, paste.
  • Firefox: Cmd/Ctrl+Shift+O, Organize, New Bookmark, paste.
  • Safari has no add-by-URL, so use the drag link.
